# Небесный Престол

Фэнтези idle-RPG для телефона: главный герой четырёх классов, 42 героя шести фракций с редкостями от R до LR, 600 этапов кампании, арена, союзы, война кланов, недельное событие, призывы, Колесо Небес, скины и достижения. Игра работает без сервера и без интернета: прогресс хранится на устройстве.

Версия **2.3.0** «Серверы и языки»: экран входа с выбором сервера (пока один — EU · Европа, сервер 1) и до 4 персонажей, автосохранение каждого персонажа, 20 языков (по умолчанию английский), защищённые сохранения. Версия 2.2 добавила 21 звезду со слиянием, уровни до 500 с возвышением R1 и Зенитом, героев LR, платные события, питомцев, крылья, артефакты, снаряжение и сюжет на 30 глав. Список изменений — в [CHANGELOG.md](CHANGELOG.md).

## Что где лежит

| Папка или файл | Что это |
|---|---|
| `src/` | Исходный код игры: HTML, JavaScript, шрифты, иконки. Править нужно здесь. |
| `i18n/` | Переводы: `keys.tsv` — все строки игры (создаётся сборкой), `en.tsv`, `uk.tsv`, `pl.tsv` и ещё 16 языков — «номер строки → перевод». Русский — язык исходников. |
| `www/` | Собранная игра (`npm run build`): один сжатый `app.js` в замкнутой области видимости, словари `lang/*.js`, офлайн-кэш. Её публикует сайт и упаковывают приложения. В репозитории не хранится. |
| `resources/` | Иконка 1024×1024 и заставка 2732×2732. Из них автоматически делаются все размеры для Android и iOS. |
| `capacitor.config.json` | Настройки приложения: идентификатор `com.vantastack.celestialthrone`, название, цвета. |
| `scripts/` | Сборка (`build.mjs`), локальный сервер, проверки словарей и кода, смоук-тест, проверка защиты, обход всех экранов, симуляция прохождения без доната, донастройка нативных проектов. |
| `.github/workflows/` | Автоматика GitHub: проверка, сайт, сборки Android и iOS. |
| `STORE_RELEASE.md` | Как выпустить игру в Google Play и App Store. |
| `PRIVACY.md` | Политика конфиденциальности для магазинов. |

Код игры в `src/`: `i18n.js` — языки и перевод строк, `data.js` — данные (герои, главы, сюжет, питомцы, крылья, артефакты, платные события), `art.js` — графика, `game.js` — экономика и прогресс, `battle.js` — бой, `ui.js` и `ui2.js` — основные экраны, `ext.js` — снаряжение, звёзды, крылья, питомцы, артефакты, платные события и Летопись, `meta.js` — почта, достижения, обучение и запуск.

## Как загрузить на GitHub

1. Создайте пустой репозиторий на github.com (без README).
2. В папке проекта выполните, подставив свой адрес:

       git remote add origin https://github.com/ВАШ_ЛОГИН/nebesny-prestol.git
       git push -u origin main

3. Сайт: **Settings → Pages → Source: GitHub Actions**. После следующего push игра откроется по адресу `https://ВАШ_ЛОГИН.github.io/nebesny-prestol/`.

После этого каждый push в `main` сам проверяет игру, обновляет сайт и собирает приложения.

## Что собирает GitHub Actions

| Сценарий | Когда запускается | Что получается |
|---|---|---|
| **Проверка** | каждый push и pull request | сборка, словари, синтаксис, версии, смоук-тест, проверка защиты и обход всех экранов в браузере |
| **Веб-версия** | push в `main` с изменениями в `src/` или `i18n/` | сборка и сайт на GitHub Pages, работает офлайн и ставится на главный экран |
| **Android** | push в `main`, тег `v*`, вручную | `…-debug.apk` всегда; подписанные `.apk` и `.aab` — если заданы секреты подписи |
| **iOS** | push в `main`, тег `v*`, вручную | `…-unsigned.ipa` всегда; подписанный `…-appstore.ipa` — если задан ключ App Store Connect |

Готовые файлы: вкладка **Actions** → нужный запуск → раздел **Artifacts** внизу страницы.

### Выпуск версии
1. Поднимите версию в `package.json` и `VERSION` в `src/data.js` (проверка следит, чтобы они совпадали), допишите `CHANGELOG.md`.
2. Отправьте тег:

       git tag v2.3.0
       git push origin v2.3.0

3. Сборки приложатся к релизу на вкладке **Releases**. Если заданы ключи, AAB уйдёт во внутреннее тестирование Google Play, а IPA — в TestFlight.

### Секреты (Settings → Secrets and variables → Actions)

**Android — подпись для Google Play**

| Секрет | Значение |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | файл ключа в base64: `base64 -w0 release.jks` |
| `ANDROID_KEYSTORE_PASSWORD` | пароль хранилища |
| `ANDROID_KEY_ALIAS` | имя ключа |
| `ANDROID_KEY_PASSWORD` | пароль ключа |
| `PLAY_SERVICE_ACCOUNT_JSON` | необязательно: JSON сервисного аккаунта Google Play для автозагрузки |

Ключ создаётся один раз и хранится всю жизнь приложения (потеряете — не сможете обновлять игру):

    keytool -genkeypair -v -keystore release.jks -alias prestol -keyalg RSA -keysize 2048 -validity 10000

**iOS — подпись для App Store**

| Секрет | Значение |
|---|---|
| `APPSTORE_KEY_ID` | ID ключа App Store Connect API |
| `APPSTORE_ISSUER_ID` | Issuer ID с той же страницы |
| `APPSTORE_PRIVATE_KEY` | содержимое файла `AuthKey_XXXX.p8` целиком |
| `IOS_TEAM_ID` | Team ID из developer.apple.com → Membership |

Ключ создаётся в App Store Connect → Users and Access → Integrations → App Store Connect API, роль **Admin**. Сертификаты и профили Xcode создаст сам. Нужна платная учётная запись Apple Developer, а приложение с идентификатором `com.vantastack.celestialthrone` должно быть заведено в App Store Connect.

## Запуск на компьютере

Нужен Node.js 22 или новее.

    npm install
    npm start              # разработческая сборка на http://localhost:8080 (переменные игры видны в консоли)
    npm run start:prod     # выпускная сборка, как в магазинах
    npm run build          # собрать www/
    npm run check          # словари, синтаксис, версии
    npx playwright install chromium
    npm test               # сборка + проверки + смоук-тест + проверка защиты
    npm run test:crawl     # нажать каждую кнопку на каждом экране на 6 языках
    npm run sim            # симуляция прохождения без доната (по умолчанию 900 дней, 3 прогона)

### Переводы
Строки на русском в `src/` сборка сама оборачивает в функцию перевода и записывает в `i18n/keys.tsv` с постоянным номером. Перевод — строка `номер<TAB>текст` в `i18n/<язык>.tsv`; чего нет в словаре, показывается по-английски. Английский, украинский и польский переведены полностью, включая сюжет; остальные 16 языков — весь интерфейс и игровые данные, а сюжет и длинные тексты пока на английском. Проверка: `node scripts/i18n-check.mjs`.

### Android на своём компьютере
Нужны JDK 21 и Android Studio Otter (2025.2.1) или новее.

    npm run android:init
    npx cap open android      # или: cd android && ./gradlew assembleDebug

### iOS на своём Mac
Нужен Xcode 26 или новее.

    npm run ios:init
    npx cap open ios

После изменений в `src/` или `i18n/` выполните `npm run sync` (он сам пересоберёт `www/`). Папки `android/` и `ios/` создаются автоматически и не хранятся в репозитории; если начнёте менять нативный код вручную, уберите их из `.gitignore` и закоммитьте.

## Важно знать
- **Неподписанный IPA** нельзя просто установить на iPhone: его нужно переподписать своим Apple ID (например, через Sideloadly или AltStore) или собрать подписанную версию с ключом App Store Connect.
- **Покупки золота.** В веб-версии они работают в тестовом режиме: золото выдаётся бесплатно. В приложениях для магазинов эти кнопки скрыты. Настоящие покупки подключаются через Google Play Billing и StoreKit (например, плагином RevenueCat) — подробности в `STORE_RELEASE.md`.
- **Онлайн.** Арена, союзы и войны кланов пока идут против компьютерных соперников. Для настоящего мультиплеера понадобится сервер.
- **Защита.** Сохранения зашифрованы и подписаны; изменённое вручную сохранение не загрузится. Старый код сохранения нельзя загрузить поверх более нового прогресса того же персонажа (защита от «отката» после неудачного призыва). Перевод часов назад не даёт ни нового дня, ни добычи, а новый игровой день наступает не раньше чем через минуту игры после прошлого — «прокрутить» месяц переводом часов становится очень долгим. В выпускной сборке код игры сжат и закрыт: из консоли браузера его переменные недоступны, встроенные чужие скрипты запрещены (CSP). В приложениях отладка WebView выключена, а резервное копирование данных через adb запрещено. Полностью невзламываемой офлайн-игры не бывает: всё, что работает без сервера, в итоге можно разобрать и изменить на своём устройстве. Настоящая защита — сервер, который хранит прогресс и проверяет покупки; для онлайн-режима это обязательно.
- Шрифты Forum, PT Serif и Rubik распространяются по лицензии SIL Open Font License, тексты лицензий лежат в `src/fonts/`. Шрифты урезаны до латиницы (включая польский, чешский, румынский, турецкий) и кириллицы; китайский, японский, корейский, арабский, хинди и вьетнамский используют системные шрифты телефона.
